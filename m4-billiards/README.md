# 台球式指尖足球 — M4 引擎与 M3 界面说明

玩法从「足球单球」改为「台球式 3 球回合制」。

---

## 玩法规则（已定稿）

| 项目 | 规则 |
|---|---|
| 节奏 | **回合制**：双方轮流击球 |
| 母球 | 玩家 0 用右半场白球（蓝环）攻右门；玩家 1 用左半场白球（黄环）攻左门 |
| 目标 | 用母球借力撞击「足球⚽」，把足球撞进**对方球门** |
| 得分 | 足球进右门 → 玩家0 得分；足球进左门 → 玩家1 得分 |
| 犯规 | 任一母球进任意球门 → 对方得分 |
| 回合 | 无进球无犯规 → 球停原地，换对方（可借力布局多回合） |
| 胜负 | 先到 5 分胜 |

## 交互（拖拽瞄准）

- 拖拽你的母球（右半场蓝环白球）
- 出现**金色方向箭头**（指向拖拽方向）+ **力度百分比**
- 松手击球，力度与拖拽距离成正比

## 真实球场背景

- 草皮横向条纹（修剪纹路）
- 白色边线、中线、中圈、中点
- 两侧禁区（罚球区）、球门区（小禁区）、罚球点
- 左右球门 + 球网

## 验证

### 引擎自测
```bash
cd m4-billiards
node selftest.js
```
预期：确定性 / 敏感性 / 进球 / 犯规 / 回合切换 5 项全过。

### 界面
浏览器打开 `m3-web/index.html`：
1. 模拟登录 → 选场次 → 开始匹配 → 超时/扩大范围进对局
2. 拖拽你的母球瞄准，松手击球
3. 观察母球撞足球、足球进球门得分
4. 先到 5 分结算

## 关键确定性设计（防作弊基础）

- 全程整数，`Math.trunc` 向零取整，禁浮点
- 球-球碰撞：等质量完全弹性，冲量 `j = dot/distSq`（定点，无需开方）
- 位置分离用整数开方 `isqrt`（牛顿迭代，确定性）
- `MAX_SPEED=180 < 2*BALL_R(220)`，防高速隧穿
- 状态指纹含 seed + 回合 + 比分 + 击球数 + 全部球位/速度/进袋状态
